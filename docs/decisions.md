# Decisions

Why the stack is what it is, so nobody (human or agent) re-litigates it by accident. Changing one of these is
fine — but do it deliberately, update this file, and migrate the whole app rather than mixing approaches.

| Area              | Choice                                                                                                                                                                                                                                                                                                                                                                                                                | Why                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                             | Revisit if…                                                                                                                  |
| ----------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ---------------------------------------------------------------------------------------------------------------------------- |
| Framework         | **Expo** (React Native, New Architecture)                                                                                                                                                                                                                                                                                                                                                                             | React Native team's recommended framework; one TypeScript codebase for iOS + Android with truly native UI; huge ecosystem; agents know it well; first-class native escape hatches (config plugins, Swift/Kotlin modules).                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                       | You need a game engine or heavy 3D (use a game engine instead).                                                              |
| Native projects   | **CNG** — `ios/`/`android/` generated, git-ignored                                                                                                                                                                                                                                                                                                                                                                    | Upgrades are `npx expo install expo@next` instead of hand-merging Xcode/Gradle projects; native config is declarative and reviewable.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                           | An SDK needs edits no config plugin can express.                                                                             |
| Routing           | **Expo Router** + native stack + **NativeTabs**                                                                                                                                                                                                                                                                                                                                                                       | File-based, typed routes, deep links for free; real platform navigation (Liquid Glass tab bar on iOS 26, Material 3 on Android).                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                | —                                                                                                                            |
| Styling           | **StyleSheet + tokens + `makeStyles`**                                                                                                                                                                                                                                                                                                                                                                                | Zero dependencies and build magic, never breaks on SDK upgrades, fastest possible at runtime, and every agent writes it fluently.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                               | You strongly prefer Tailwind classes → NativeWind or Uniwind (one or the other, everywhere).                                 |
| Server state      | **TanStack Query**                                                                                                                                                                                                                                                                                                                                                                                                    | Caching, retries, refetch-on-focus, mutations, offline-friendly; industry default.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                              | —                                                                                                                            |
| Client state      | **zustand**                                                                                                                                                                                                                                                                                                                                                                                                           | Tiny, hook-based, no providers, trivial persistence.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                            | —                                                                                                                            |
| Validation        | **zod 4**                                                                                                                                                                                                                                                                                                                                                                                                             | Runtime validation of API responses, env and stored JSON with inferred TS types.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                | —                                                                                                                            |
| Local storage     | **expo-sqlite kv-store** (sync)                                                                                                                                                                                                                                                                                                                                                                                       | Works in Expo Go, synchronous (no loading flicker), and the same package gives a full SQLite DB later.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                          | Profiling shows KV is hot → `react-native-mmkv` (needs a dev build).                                                         |
| Audio engine      | **react-native-audio-api** (Software Mansion, Web Audio API), wrapped by `src/features/audio/audio-engine.ts`                                                                                                                                                                                                                                                                                                         | A real audio graph: sample-accurate clip scheduling (`AudioBufferSourceNode.start(when, offset, duration)`), per-track gain, offline mixdown (`OfflineAudioContext`), recorder with live buffers and lossless WAV output, background recording via its config plugin. `expo-audio` plays/records single files but can't schedule many clips in sync. Needs a development build.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                 | The library stalls or a needed feature (e.g. time-stretch) is missing → native module of our own behind the same engine API. |
| Project data      | **SQLite** (`src/lib/db.ts`): projects → tracks → clips, clips point at immutable **takes** (WAV files); projects → **sections** (T18 labels, never overlapping)                                                                                                                                                                                                                                                      | Non-destructive editing: trim/move/split only change `start`/`offset`/`duration` (seconds), audio files are never rewritten. Take paths are stored **relative** to the document directory because iOS changes the absolute container path. The Ideas list reads through TanStack Query; the open idea is owned by a zustand **editor store** (`src/features/project/editor-store.ts`): every edit is a snapshot of the rows it touches (undo = swap before/after), applied in memory, written through to SQLite in a serial queue, 100 undo steps in memory per open idea. Takes no clip uses are deleted when an idea opens. **Folders** (T19) nest without a depth limit; the Ideas tab loads every folder and idea and derives each view (root, folder, Favorites, search, Move sheet) with pure tree logic (`src/features/projects/folder-tree.ts`). `projects.folder_id` is ON DELETE SET NULL, not CASCADE: real deletion (`purgeItems` / `purgeExpired` in `trash-repo.ts`) removes a folder's ideas' rows and audio files first, so a cascade could only ever orphan audio. Delete is soft (T41): `deleted_at` on `projects` and `folders`, one shared stamp per deleted subtree, listed in Recently Deleted for 30 days, then purged at launch. Favorites is a flag (`projects.favorite`), not a folder. Starring and moving don't touch `updated_at`. | Cloud sync is added → keep IDs as UUIDs (already) and add sync metadata.                                                     |
| Speaker mode      | **Offline echo cancellation** after Stop, in a local Expo module (`modules/echo-canceller`, C core + Swift)                                                                                                                                                                                                                                                                                                           | Recording without headphones: the backing heard from the speaker is removed from the take using the exact mix that played. Fixed speaker → room → mic filters estimated once per take (with a distortion model) beat the platforms' voice processing (thin, gated, call audio mode) and SpeexDSP's adaptive canceller (drifts while the performer plays). Raw take kept. **Shelved (T42, 2026-11-14): off everywhere behind `SPEAKER_MODE_ENABLED` in `@/lib/echo-canceller`, code kept.** Optional and off by default; recording in silence with a visual metronome (T33, T34) is the main path.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                               | Real-time monitoring needs, or a much better library appears.                                                                |
| Loop playback     | **Reschedule every clip each pass** on the context clock, a pass ~1 s ahead, with a 5 ms crossfade where the loop cuts a clip (`loop-math.ts`)                                                                                                                                                                                                                                                                        | The library's buffer-source `loop` repeats one buffer only; a multitrack loop needs every clip restarted per pass. Scheduled ahead on the audio clock it's sample-accurate (gapless), and the crossfade removes the click of cutting a waveform mid-cycle. Recording ignores the loop (T26).                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                    | Loop recording (takes per pass) is designed.                                                                                 |
| Clip gain & fades | **One `GainNode` per scheduled clip** playing its envelope (`clip-envelope.ts`): clip gain, linear fades, a 3 ms declick on every edge except seamless split joints                                                                                                                                                                                                                                                   | Gain and fades stay non-destructive (numbers on the clip, never baked into the take). Linear ramps between the envelope's corners reproduce it exactly from any start point (mid-clip, loop passes). Declicking every edge stops pops at trimmed edges; skipping it where two pieces of one take meet keeps a split inaudible.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                  |
| Pitch keyboard    | **Synthesized** tone (a few sine partials via `createPeriodicWave`, attack/decay/release) on the playback `AudioContext`, through its own bus to the speakers                                                                                                                                                                                                                                                         | No sample files to ship, instant response, works during playback, and it can't end up in a take (other than via the mic) or on the timeline: a pitch reference, not an instrument.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                              |
| Export            | **Offline render with Play's own graph code** (`audio-graph.ts` → `OfflineAudioContext`, `offline-render.ts`), WAV written in JS, M4A by a local Expo module (`modules/audio-export`), zip with **fflate**, shared with **expo-sharing**                                                                                                                                                                              | The file can't drift from what Play sounds like: clip scheduling, envelopes and track gains are the same functions on either context. The audio library renders but can't encode a buffer, and AAC needs the platform encoder (`AVAudioFile` / `MediaCodec`); WAV and the MIDI tempo map are a few lines of JS. Stems and batch zips are stored (no compression) and streamed to disk one entry at a time. expo-sharing shares one file, so the module also opens a share sheet for several.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                    | The library gains an encoder → drop `encodeM4A`.                                                                             |
| Inputs & outputs  | **Library device API + a small local module** (`modules/audio-input`); a multi-channel input is recorded whole and the chosen channel extracted to mono after Stop; one latency offset per output route (speaker / wired / Bluetooth / USB)                                                                                                                                                                           | `react-native-audio-api` lists and selects inputs (`getDevicesInfo`, `setInputDevice`) but averages an interface's channels into a mono take, and exposes no channel count, input gain or route button: the module adds those (`AVAudioSession`, `AVRoutePickerView`, `AudioDeviceInfo.channelCounts`) and a native channel extractor. Takes stay mono. Output latency differs by route by 100+ ms, so one global offset can't fit. Bluetooth: phone mic + A2DP by default (good playback); the headset mic (HFP, or iOS 26 high-quality recording) is opt-in. All choices live in Settings; the editor only shows clipping on its meter.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                       | The library gains channel selection → drop `extractChannel`; stereo takes (Backlog) → record two channels as-is.             |
| Interruptions     | **Stop and save, never auto-resume** (T7). A call, Siri, an alarm, another app taking audio focus, the Android notification's Stop or a recorder error ends the take there and saves it, with a note; playback pauses. Interruptions are observed only while playing or recording. Android: a recording notification (Stop button, chronometer) runs the microphone foreground service; `androidFSStopWithTask: true` | iOS resumes the recorder by itself after an interruption, leaving a gap the take can't line up across. On Android, observing interruptions requests audio focus, which would pause the user's music while the app is merely open. Swiping the app away is a "quit": the library finalizes the WAV natively, but the take isn't added (recovering it is a Backlog ticket).                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                       | Users want to resume a take after a call → a paused-recording state, recording into a new take aligned at the resume point.  |
| Drawing           | **@shopify/react-native-skia** for the timeline: one `<Canvas>` whose picture is rebuilt per frame on the UI thread (`createPicture` in a `useDerivedValue`)                                                                                                                                                                                                                                                          | GPU drawing keeps long waveforms and many clips smooth at 60fps without React renders. Time runs left to right (a vertical portrait timeline was tried in T2 and dropped: harder to read than the familiar horizontal one; T43 brought it back as an experimental Settings switch, the same timeline drawn transposed: `timeline.tsx` works in logical time / lane axes). Waveforms share one vertical scale per project (loudest take fills its lane, linear amplitude), so relative loudness stays true. Waveforms come from cached `<takeId>.peaks` files (min/max per 256 samples, plus coarser levels for zooming out). The playhead runs on the UI thread from an anchor on the `performance.now()` clock. The JS and worklet runtimes **don't** share a time origin (seen ~29 h apart on iOS), so anchors are converted with a measured offset (`src/features/project/ui-clock.ts`).                                                                                                                                                                                                                                                                                                                                                                                                                                                                     | Many tracks × long ideas get slow → cache a picture per clip, or draw with `Atlas`/textures.                                 |
| Orientation       | **Portrait only** (`"orientation": "portrait"` in `app.json`, iPhone only)                                                                                                                                                                                                                                                                                                                                            | It's how the app is meant to be used, and a phone in landscape leaves the timeline too little height for its lanes. One layout also means one layout to design and test.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                        | A real landscape use case appears (e.g. iPad) → add a layout for it and test both.                                           |
| Unit/component    | **Jest + jest-expo + RNTL 14**                                                                                                                                                                                                                                                                                                                                                                                        | Expo's supported setup; RNTL tests behave like users and ship agent docs in `node_modules`.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                     | —                                                                                                                            |
| E2E               | **Maestro**                                                                                                                                                                                                                                                                                                                                                                                                           | YAML flows that are easy for humans and agents to read/write; no native test code; works on simulators and EAS.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                 | You need deep native assertions → Detox.                                                                                     |
| Lint/format       | **ESLint (eslint-config-expo + react-hooks compiler rules) + Prettier**                                                                                                                                                                                                                                                                                                                                               | Expo-supported config, React Compiler rules, guardrails for the design system; Prettier keeps diffs clean. **ESLint stays on v9** (the version `npx expo install` picks): on v10, `eslint-plugin-react` inside eslint-config-expo crashes (`getFilename is not a function`).                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                    | A future eslint-config-expo supports ESLint 10 — then upgrade with `npx expo install eslint`.                                |
| Package manager   | **npm**                                                                                                                                                                                                                                                                                                                                                                                                               | Zero setup, default everywhere (EAS, CI), fewest surprises.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                     | Install speed matters a lot → bun.                                                                                           |
| Build & delivery  | **EAS** Build / Submit / Update / Workflows                                                                                                                                                                                                                                                                                                                                                                           | Cloud builds without Xcode, managed signing credentials, one-command store submission, OTA updates, CI-like workflows.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                          | Org mandates self-hosted CI → `eas build --local` or Fastlane.                                                               |
| OTA compatibility | **`runtimeVersion.policy: fingerprint`**                                                                                                                                                                                                                                                                                                                                                                              | Automatically prevents shipping JS to an incompatible native build.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                             | —                                                                                                                            |
| Variants          | **`APP_VARIANT` in `app.config.ts`**                                                                                                                                                                                                                                                                                                                                                                                  | Dev, preview and production install side by side with distinct names/IDs.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                       | —                                                                                                                            |
| Platforms         | **iOS + Android only**                                                                                                                                                                                                                                                                                                                                                                                                | Focus; fewer platform branches.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                 | You want a web version → add `react-dom` + `react-native-web`.                                                               |
| Repo shape        | **One app per repo** (cloned from the base)                                                                                                                                                                                                                                                                                                                                                                           | Simple for humans and agents; each app evolves and upgrades independently.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                      | Several apps share lots of code → monorepo with shared packages.                                                             |
| Base updates      | **Shared git history + `npm run sync-base`** (merges `base/main`)                                                                                                                                                                                                                                                                                                                                                     | A real 3-way merge carries every kind of base change (tooling, skills, design-system fixes, SDK bumps in package.json) and only conflicts where the app changed the same lines; `TICKETS.md` stays the app's. Rejected: patches on a fresh history (more custom code, weaker on deletions/binaries) and overwriting "base-owned" folders (clobbers app edits, can't carry SDK upgrades).                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                        | Apps diverge so far that syncs are mostly conflicts → stop syncing that app, or move shared code into packages.              |
